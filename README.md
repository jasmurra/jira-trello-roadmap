# Jira → Trello Roadmap Sync

Local Mac app that compares a Jira board to a Trello roadmap board, then lets you create or edit Trello cards. Each person signs in with **their own** Jira and Trello accounts.

## Install (coworkers)

You do not need to clone this repository.

1. Download **[Jira-Trello-Roadmap.zip](https://github.com/jasmurra/jira-trello-roadmap/releases/latest/download/Jira-Trello-Roadmap.zip)** from the latest [GitHub Release](https://github.com/jasmurra/jira-trello-roadmap/releases/latest).
2. Unzip it and double-click `start.command`.
3. Sign in to Jira and Trello, pick your boards, then Compare.

Keep the Terminal window open while you use the tool. Later versions install themselves — **Check for updates** or restart `start.command`. You do not need a new zip after the first install.

Details are in `START HERE.txt`.

## Maintainer

Build a coworker zip on the Desktop:

```bash
./share-for-mac.command
```
